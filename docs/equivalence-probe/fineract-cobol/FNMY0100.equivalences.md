# Verified library equivalences: FNMY0100

These facts were established by the pipeline, not guessed. FNMY0100's CALLs, 20,865 traced from the faithful program over 31 oracle scenario(s), and up to 100,000 generated CALLs per group (inputs drawn from the traced ones, run through the faithful program), were replayed through a catalog of JDK operations. Each statement below reproduced every byte of every checked CALL (all output fields and the return code) where its condition holds. Implement these groups with the named JDK operation (BigDecimal, MathContext, RoundingMode, LocalDate, ChronoUnit) and the stated field mapping; do not re-derive the COBOL digit or calendar algorithm. A decimal pair is a BigDecimal: new BigDecimal(COEF, -EXP) has the value COEF × 10^EXP.
